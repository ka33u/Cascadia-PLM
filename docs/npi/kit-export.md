# 齐套物料导出

规格书图28-1的齐套页包含导出入口。“样机齐套物料”现提供“导出当前筛选（N项）”，下载 Excel 工作簿。

- 导出点击时的全部筛选结果，包括未显示在当前分页中的行；搜索、来源、状态和已完成／未完成筛选均生效。定位物料时只导出该物料。
- 工作簿顶部记录项目、筛选范围、导出时间、要求齐套、制造承诺与系统预测；回复不完整和已齐备沿用系统计算结果。
- 保留物料编码、规格、来源、类型、BOM版本／行号、数量、单位、责任人、要求／首次承诺／当前承诺／实际日期、状态、跟踪与齐套标记、修改次数、供应商、备注和齐套瓶颈标记。
- 物料编码和数量按文本写入，避免前导零丢失及Excel数字精度限制；用户输入作为文字，不生成公式。状态颜色由已有业务状态决定。
- 没有匹配结果时按钮禁用。导出失败保留筛选条件，可直接重试。导出只使用已获准查看的数据，不写业务数据库。

清单是跟踪物料的状态快照，不是库存报表；未跟踪当前BOM数量仍在页面单列。完整BOM和导入原始Excel有各自的查看／下载入口。

验证：2项工作簿测试检查写出再读取、编码与高精度数量、文字公式安全、日期、版本、过滤器、冻结表头及跨页导出；2项DOM测试检查实际筛选、定位、空结果、文件名和失败恢复；2项原有物料表单／来源筛选测试通过。实际项目类型检查与构建通过。独立Chrome针对当前构建验证了桌面26项导出、手机筛选1项导出、合法高精度数量、空结果禁用、无页面错误、无横向溢出及无业务写入。

## 浏览器验证

导出按钮并入筛选栏；桌面与手机均可直接下载当前筛选的全部结果。测试使用隔离数据库与独立无头Chrome，仅覆盖齐套导出，不代表其他待验页面已通过。

截图：[桌面](screenshots/kit-export-desktop.png)、[手机](screenshots/kit-export-mobile.png)。结果见 [验证记录](kit-export-browser-verification.json)。截图和工作簿均为合成测试数据。

在已构建的项目根目录运行：

```sh
TSX_TSCONFIG_PATH=packages/core/tsconfig.json node --env-file=.env --import tsx scripts/npi-kit-export-browser.test.ts
```

要求显式配置以 `_test` 结尾的 `TEST_DATABASE_URL`，并安装Chrome。可通过 `NPI_BROWSER_APP_ROOT` 指定已构建应用根目录；测试自选临时端口，不使用用户浏览器窗口。

瓶颈列与页面一致；回复不完整时显示“已知瓶颈（预测不完整）”。详见 [瓶颈定位](bottleneck-focus.md)。

预测不完整的具体原因已区分待回复和BOM换版待复核，见 [最新提示与截图](prediction-completeness.md)。本页较早截图保留原验证轮次文案。
