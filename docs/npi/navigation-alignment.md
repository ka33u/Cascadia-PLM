# 规格书导航与页面职责对齐

依据：V1.4 规格书第19、28、29节及嵌入原型图28-1，结合用户取消独立新品例会、指出制造工作台重复的反馈。原型用于业务布局与入口对齐。

| 入口     | 页面职责                                                                         |
| -------- | -------------------------------------------------------------------------------- |
| 首页     | 新品驾驶舱，六项指标、项目进度、待办、风险与今日变化                             |
| 新品项目 | 项目目录，按名称、编号、型号、阶段查找；每页25个，进入项目概览                   |
| BOM管理  | 项目当前BOM、原件名称、版本数与待复核数量；直接进入该项目的BOM页并加载当前结构   |
| 制造准备 | 制造四节点任务；状态、节点、负责人筛选，直接集中回复，进入项目确认完成及查看历史 |
| 采购管理 | 管理岗位查看可见项目的采购物料并定位齐套明细；采购账号只处理本人采购任务         |
| 报表看板 | 项目与阶段筛选、阶段分布、完成项目按期率、完成明细分页、今日变化及累计改期任务   |
| 基础数据 | 导入模板维护、当前阶段／节点／完成和预测规则说明                                 |
| 系统设置 | NPI业务岗位分配、原生系统用户管理入口                                            |

管理员显示八个入口，技术、制造与主管显示前六个，采购显示自己的采购管理入口。所有列表使用原有后端可见范围；主管可调整计划并查看历史，承诺和完成仍由责任人办理，见[当前主管权限](supervisor-planning.md)。技术／制造被分配的其他项目物料保留独立访问，不因此扩大项目权限。

项目详情返回按钮保留进入模块；从BOM入口进入时先加载项目对应的BOM结构和换版复核数据，从采购物料进入时定位该物料。首页移出累计改期任务的完整列表，今日变化仍保留。

## 验证范围

候选版标准类型检查、构建、相关文件ESLint、8项概览／瓶颈／预测回归通过。独立浏览器使用显式隔离的 _test 数据库，26个临时项目、6个临时账号与真实解析的测试BOM，验证项目分页／筛选、八个不同模块、BOM结构加载、四节点筛选及集中回复入口、采购物料定位、报表阶段筛选、模板编辑入口、岗位页面分离与角色可见范围。测试后清理本次创建的项目、账号、BOM和模板。

主管专项测试确认移入报表看板后，次数筛选、已完成记录、排序、定位及完整承诺历史仍可用，浏览器无业务写请求。同步后的实际构建通过八模块专项浏览器验证，覆盖1280×640较矮窗口侧栏滚动、1440×1000桌面与390×844手机布局。3410正在提供新导航和模块组件，页面返回200，匿名API返回401。详见 [验证记录](navigation-browser-verification.json)，[桌面制造准备](screenshots/navigation-manufacturing-desktop.png)和[手机制造准备](screenshots/navigation-manufacturing-mobile.png)。截图为隔离测试数据。

旧的完整BOM浏览器脚本已更新受导航变动影响的选择器和制造任务断言，本轮未重跑其全部流程。本次专项验证不替代全部规格书签收、真实项目试运行或其他待验场景。

制造准备的快捷回复已进一步缩短为点击任务、填写日期、保存三步，支持冲突恢复与迟到导航保护，见[后续交付](manufacturing-quick-reply.md)。
