# BOM导入模板维护

管理员从左侧“基础数据”进入，选择“新建导入模板”或现有模板的“编辑映射”。一个模板对应一种ERP导出格式，物料内容和电机型号不固定。人员岗位分配位于独立的“系统设置”入口。

## 填写表单

1. 模板名称便于辨认；工作表名称须与Excel底部标签一致。
2. 表头所在行是列标题所在行；数据起始行必须晚于表头。表头支持第1至100行，数据起始行支持第2至200行。
3. 选择加号层级（+、++、+++）或数字层级（1、2、3）。
4. 填写母件编码、名称、规格的单元格，例如A4、B4、C4。表单保存时去除首尾空格并统一大写。
5. 字段映射填写Excel表头原文。层级、物料编码、物料名称、基本用量四项必填；可选列不存在时留空。留空会移除该可选映射。
6. 勾选“启用此模板”后保存，技术负责人即可在项目ERP BOM页面选择它并解析。先核对预览，再确认导入。

改变列标题、工作表或层级格式后，应使用一份对应格式的原始Excel重新预览，确认母件、行数、层级和数量。

## 启用和停用

模板列表显示“已启用”或“已停用”。新建时可以保存为停用；编辑时保留当前选择。停用模板不会参与新预览，已生成但未正式导入的预览也不能在停用状态下确认导入。已导入BOM版本保留原模板快照和原始Excel，仍可查看、下载。

## 失败和多人编辑

保存失败时，填写内容继续保留，可核对提示后重试。若另一位管理员已经修改模板，旧版本保存会被拒绝，不覆盖对方修改。可以继续核对当前输入；点击“载入最新模板（放弃本次修改）”才会用最新配置替换本次未保存内容。

## 高级配置

“高级配置（JSON）”面向需要维护额外映射的管理员。点击“返回表单配置”校验并应用JSON；无效内容会提示错误并保留输入。“放弃JSON修改”恢复切换前的表单内容。表单中未列出的已有映射仍保留。模板编号不可更改；新格式应通过“新建导入模板”建立独立模板。

目前只接收xlsx数值工作簿；文件、层级、数量和其他导入限制仍按系统校验执行。


## 可选的跟踪属性映射

如果ERP导出包含物料业务属性，在“跟踪属性列标题”填写该列的实际表头。没有该列时留空，系统不从物料名称、采购类型或仓库猜测新规格与交期。

支持值：核心自制加工件（也接受核心自制件、核心加工件）、新规格外购件、长周期采购件（也接受采购长周期件）、客户指定件、原材料、普通倒冲件、普通标准件（也接受标准件）、常备库存件、关键件（也接受人工关键件）。多个属性用逗号、顿号、分号、竖线或换行分隔。未知值只警告并保留原文，不产生对应建议；属性列重复时整列不参与建议，避免任取一个同名列。

一级核心自制加工件、新规格外购件建议跟踪；长周期、客户指定和关键件不限层级。普通原材料、倒冲件、标准件和库存件默认不跟踪，明确的关键、长周期、客户指定要求优先。建议不是自动派工，导入后由项目负责人在“建议待确认”中逐项指定责任人与要求日期。
