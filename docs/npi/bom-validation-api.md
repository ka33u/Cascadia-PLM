# BOM校验与错误响应

预览与正式导入分别处理：

- 可解析的Excel预览按SRS44.2返回200，包含逐行`validation`和错误/警告数量。出现任何ERROR时`previewToken=null`，不会写入可消费的预览记录，界面不能继续导入。层级错误的逐行码为`INVALID_LEVEL_SEQUENCE`，其余格式/必填字段错误为`INVALID_BOM_FORMAT`。
- 无法读取的Excel、扩展名/大小不符合限制等请求错误仍返回对应非200响应。
- 确认导入只信任服务器保存的预览，不接受客户端回传的解析行、错误列表或错误数量替代。令牌为空或不合法返回422字段校验；过期、已消费或项目版本变化返回409。
- 正常无错误预览才有令牌。对于历史或异常暂存数据，确认接口同时检查错误计数及逐行ERROR，任何一方表明失败就拒绝；不能通过把计数清零绕过。
- 暂存预览含层级ERROR时，确认返回400 `INVALID_LEVEL_SEQUENCE`；其余ERROR返回400 `INVALID_BOM_FORMAT`。同时存在多种错误时层级错误优先；错误消息包含原工作表行号和修正后重新预览的指引。只有错误计数、没有逐行信息的旧数据仍以通用格式错误拒绝。
- WARNING/INFO不阻止导入；失败不会消费令牌、建立导入版本或改变项目/跟踪/承诺。修正文件后应重新上传，不能编辑服务器暂存预览来代替重新解析。

HTTP回归覆盖实际错误工作簿的无令牌行为，以及显式注入异常暂存数据后的拒绝、事务无写入和后续正常导入。异常暂存注入仅用于隔离测试库，不代表正常用户能修改服务器预览。

第47章通用错误码表不能机械套用到预览的每一个行级错误，否则会破坏第44.2章要求的完整预览反馈。本文明确当前接口语义，并未声称所有预览校验都会返回HTTP400。错误码在相应的行级诊断或确认接口兜底响应中保持明确。
