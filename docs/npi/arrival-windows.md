# 采购到货范围与责任人筛选

规格书第12节要求采购待回复、风险、逾期和未来7／14天到货清单，第19.7节要求采购人员便捷维护交期。管理端现在可组合使用采购责任人、当前承诺到货范围、任务状态及关键词，个人采购清单新增“今日到货”。

## 日期与范围

- 今日到货：当前承诺日期等于所显示的业务日期，且尚未记录实际到货。
- 未来7／14天：延续原个人清单口径，包含今日至今日加7／14天的截止日。界面直接显示起止日期，避免把它理解为不含今日的自然日数量。
- 使用当前承诺，不使用首次承诺或要求日期；已到货、未承诺及早于今日的事项不计入近期窗口。早于今日的未到货事项仍可在逾期分类中查看。
- 选择到货窗口时按当前承诺日期从近到远排列；不限日期时保留原风险及要求日期排序。
- 管理端业务日期来自当前驾驶舱数据快照，个人清单使用北京时间当日。跨日长时间打开页面应刷新取得最新状态。

## 筛选与操作

采购责任人只列出当前可见采购任务中的人员，以用户编号精确筛选；同时展示姓名与可用邮箱区分同名用户。搜索、状态、责任人和到货范围可以组合使用，状态计数随范围变化。“清除采购条件”清除责任人和到货范围，保留关键词、状态和仅本人负责选择。

每页25项，筛选改变时返回第一页，搜索覆盖当前范围的完整数据。个人清单记录到货后保留当前筛选，新到货物料从近期清单移除。管理端可从结果直接进入项目齐套页定位物料。现有角色与项目权限继续由接口控制，主管仍只读。

手机上责任人控件独占一行。截图核查发现并修复了控件撑宽卡片的问题；后续浏览器断言同时检查页面、卡片和控件边界，覆盖320／390像素窗口。

- 6项内存组件测试：跨月／跨年／闰年边界，今日／7／14天，排序、完成排除、筛选组合、同名人员、分页重置、只读定位和制造节点入口回归。
- 候选与实际构建分别执行专项浏览器：两个临时项目、39个采购件、两个同名采购责任人；完整遍历7天31项、14天33项，跨页搜索、今日到货保存刷新、管理端组合条件、物料定位和主管只读。
- 类型检查、ESLint、Prettier、构建通过；手机截图逐张检查。日志与当前运行模块校验见[验证记录](arrival-windows-verification.json)。
