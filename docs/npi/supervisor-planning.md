# 主管计划调整

用户确认“只调整计划，承诺由责任人回复”。此规则替代早期主管全面只读的说明；历史验证记录保留其执行时的策略。

## 可执行范围

- 项目顶部“项目计划与交接”：调整名称、型号、客户/电机参数、要求齐套/样机日期及技术/制造负责人，先预览变化与交接清单，再确认。
- 未完成跟踪物料和制造节点行内“调整计划”：修改要求日期；非制造节点可交接回复责任人，并校验接任岗位。
- 所有调整须填写原因、核对版本；预览后任务发生变化则重新预览。审计记录调整人、原因与前后值。原承诺、实际完成及其历史保留。

主管不能代填承诺、确认完成或更正实际日期，不能新增物料、修改BOM/跟踪配置、推进阶段或管理岗位/模板。问题与资料维持原权限。已完成项目及已完成物料不可调整计划。原制造负责人改任主管后，任务列表、项目制造页和齐套集中回复区同样撤销回复/完成入口。

## 验证

服务专项在单一事务中验证原因、版本、接任岗位、交接、预览失效、提交时重新核对权限、审计与越权拒绝，最后回滚并验证零残留。

限定浏览器专项使用本机独立测试库和临时服务，验证1440×1000桌面、390×844手机上的六个主管导航入口、物料计划保存、项目预览/确认、交接后主管访问、承诺历史保留、真实HTTP越权拒绝、已完成记录以及原负责人改任主管的按钮权限。结束删除本次所有合成用户、项目、事件及会话，核对零残留；没有写正式业务库。截图只包含合成测试数据。
