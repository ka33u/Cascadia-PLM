# 项目问题保存与刷新恢复

项目问题页和采购端“我负责的问题”共用以下行为：

- 首次列表加载失败时，显示明确错误和“刷新问题”入口，不显示“暂无问题”。
- 保存请求失败时保留表单内容；服务端明确返回保存成功后，立即提示成功。进展备注此时清空，新建／修改表单此时关闭。
- 保存成功后，详情、列表或项目摘要刷新失败，会显示刷新错误并暂停继续提交。点击“刷新问题”或“刷新问题详情”只重新读取数据，不重新保存。
- 切换项目后，旧项目迟到的列表或详情响应不会覆盖当前内容。

验证：6 项内存 DOM 交互测试覆盖初次加载失败、保存失败保留输入、保存成功后详情／摘要刷新失败、新建成功后列表刷新失败、未收到保存响应时保留重试编号，以及项目切换。测试命令：

```sh
TSX_TSCONFIG_PATH=packages/core/tsconfig.json node --import tsx scripts/npi-issue-recovery-dom.test.mjs
```

处理记录保存未收到确认时，当前表单保留内容和提交编号，直接重试不会重复追加。保存确认后清空内容，下一次提交使用新编号。刷新整页或关闭页面后，未确认表单的编号不会跨页面保留，应先查看时间线。新建问题、修改资料、状态推进不属于本次处理记录去重范围。本轮未进行真实浏览器布局复验。
