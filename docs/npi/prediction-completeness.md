# 系统预测齐套的完整性提示

规格书19.2要求固定项目卡呈现系统预测齐套，35节规定待回复时可显示已知最大日期，但必须标明预测不完整。BOM换版后的旧跟踪复核也可能使当前预测不完整。

固定项目卡的日期下方现显示预测完整性和具体原因；概览、齐套日期卡和Excel摘要使用同一提示：

- 有关键项未回复：预测不完整 · 仍有关键项待回复。
- 仅BOM换版待复核：预测不完整 · BOM换版待复核。
- 两者同时存在：同时列出两项原因。
- 预测完整时不加不完整提示；非关键BOM复核提醒不单独改变此状态。

瓶颈标记统一为“已知瓶颈（预测不完整）”，避免将BOM复核误称为回复不完整。此改动只解释服务端已有结果，不改齐套计算、承诺历史或完成统计。

验证：2项提示逻辑、3项工作簿、2项瓶颈DOM、4项概览DOM和2项导出DOM测试通过。扩展独立浏览器测试，使用隔离_test数据库、合成项目和两次真实BOM导入：关键项日期均有回复后，换版留下旧跟踪待复核；断言服务端无PENDING_REPLY、存在BOM_REVIEW_PENDING，页面正确说明原因。桌面和手机未出现横向溢出或页面异常。
