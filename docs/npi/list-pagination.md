# 采购清单与报表明细分页

依据规格书19.1、19.7、20、22和28.5的异常优先、列表搜索筛选与手机操作要求，为采购本人清单、今日变化、累计承诺改期任务增加分页。三处均每页25条，顶部和底部共享页码，可到首页、末页、前后翻页或选页跳转。

搜索、状态筛选、改期次数筛选和统计始终基于全部可见记录，随后取当前页显示。采购待办卡片保持本人全部任务的口径；页码提示区单独列出当前页、显示范围和筛选总数。首次承诺不计入改期次数，已完成／停止跟踪仍按原筛选开关纳入。

今日变化与累计改期任务分别保存页码，翻动一张表不改变另一张表；共享搜索、报表项目范围或对应筛选改变后，受影响列表回到第一页。回复／到货保存或刷新后，按新状态重新排序并回到第一页，不保留可能已经过期的页码。翻页后滚动到新页内容；原有“定位事项”继续定位所选物料。

列表复用现有分页组件，计算结果在输入未变时复用；首页隐藏累计改期任务时不再生成其完整明细。此次控制的是前端每页呈现量，API仍返回当前权限范围内的数据，不代表已经实现服务端分页或通过企业规模压力测试。所有状态和权限继续来自原服务。

## 验证

专项使用隔离 `_test` 库的两个临时项目、53个采购件、104条当天改期记录和52个累计改期任务，通过真实API验证：

- 采购3页、今日变化5页、累计改期任务3页；首末页与顶部／底部页码一致。
- 在末页搜索仍可找到其他页的记录，筛选清空后回第一页；计数涵盖全部筛选结果。
- 非首页回复后状态、风险数量及排序更新；已完成物料从当前改期任务移出，勾选包含历史后可再次查看。
- 两张报表独立翻页，切换变化类别或改期次数后正确重置；末页记录可定位到项目物料。
- 桌面／手机无横向溢出，翻页后首条记录可见；主管浏览器没有业务写请求。

测试退出清理本次创建的项目、账号和历史。标准类型检查、变更文件ESLint、构建和实际产物专项结果见 [验证记录](list-pagination-verification.json)。这不是完整规格书签收或真实业务试运行。

## 本地测试库规模观察

本轮只读统计发现共享测试库已有1,146个项目（不含本次临时夹具）。在此基础上，实际构建的刷新响应约15.2MB，专项中一次刷新接口耗时约3.6秒；这些是本机单次观测，不能用作企业性能承诺。分页已限制表格呈现行数，后续仍需缩减驾驶舱聚合接口返回内容并核对加载成本。既有测试数据未清除。
