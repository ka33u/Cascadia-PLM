# 制造快捷回复与手机操作

依据规格书19.6、22及26的制造四节点和手机回复要求，将入口缩短为：点击“集中回复” → 填写日期 → 保存制造回复。

制造准备任务列表直接打开当前项目的四节点表单，项目详情中的“集中回复”使用同一组件。首次回复只填写已确认的节点；尚未确认的节点保持待回复。只有修改已有承诺的节点显示改期原因，首次承诺与完整历史保留，已完成节点不能改承诺。

状态数量放在搜索筛选栏前，手机可先看到待回复／逾期。数量随项目搜索、本人范围及节点筛选变化；状态筛选控制下面任务明细。

保存期间禁用输入和取消，并阻止关闭弹窗。版本冲突保留输入和原因；“刷新最新计划”只读取最新数据，不直接覆盖草稿，再由用户选择“载入最新计划”并重新核对日期。读取过程中也禁用保存，避免同时操作。资料过期或权限变化仍由原API校验。

进入项目使用最新读取的项目编号、制造负责人和计划版本。用户在读取期间切换模块时，旧请求的成功或失败不再改变新页面，避免重新弹出旧项目。所有变化复用原制造计划API及权限，没有新增业务表、后台任务或通知。

## 验证

专项浏览器使用隔离 _test 库中的两个临时项目，通过真实API验证首次部分回复、项目内四节点批量回复、首次承诺保留、改期原因必填、版本冲突后保留输入、读取最新计划与显式载入、已完成节点锁定、保存期间不能误关闭、跨项目表单隔离及迟到响应取消。测试结束清理本次创建的项目、历史和账号。

八模块导航回归覆盖BOM加载、采购物料定位、主管只读、采购个人入口、手机及较矮桌面窗口。已有内嵌制造回复保持原入口，与快捷弹窗共享表单逻辑。本次不是全规格书验收或真实企业试运行。
