## 上一轮：大BOM分页与齐套口径

- 用户确认：已满足／缺料按跟踪物料实际完成／未完成统计，未跟踪物料单列。8个卡片保留ERP BOM、BOM外物料、重点跟踪、待回复、风险／逾期，并提供已满足、缺料、未跟踪明细下钻。

## 本次实现与规格书的明确差异

1. 不增加第二套项目身份，使用Program + 一对一NPI扩展表。制造节点归入npi_tracking_items，npi_manufacturing_plan作为项目唯一计划及集中回复版次；所有承诺历史只有一个事实来源。
2. 原始ERP文件目前以完整字节编码保存在PostgreSQL，与版本事务一并提交；尚未连接原生Document/Vault。文件上限限制适用于该存储方式。
3. 状态采用北京时间自然日，不将承诺当天00:00刚过即判逾期；API时间转业务日后保存。需企业确认该日期口径。
4. 制造整体齐套与样机装配不参与明细齐套预测；工艺、工装与affectsKit物料参与。无待回复但所有关键项完成时预测日期为空并提示已齐备。
5. 没有物理删除业务档案的前台接口，也没有强制覆盖冲突。需求变更、错误实际日期的受控更正及项目归档政策留待下一轮。
