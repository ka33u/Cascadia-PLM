# 协作物料资料与照片

“我的协作物料”每行提供“资料与照片”入口。当前接收人为技术或制造人员时，可以查看该物料的技术说明、下载附件，并上传技术资料或照片。适用于 BOM 物料、临时样机件和其他物料。

权限按物料当前责任人判断，不授予整个项目或原生资料空间的访问权限。交接后，原接收人失去该物料的附件访问权，包括其自己上传的文件；新接收人可以查看历史附件。资料归档由项目技术负责人、制造负责人或管理员处理。

停止跟踪且不影响齐套的物料、已完成项目的附件只读。已归档资料继续保留，可勾选“显示已归档资料”追溯。上传沿用 PDF、PNG、JPEG、WebP 和单个 5 MB 限制。

上传失败保留所选文件以便重试。上传成功但列表刷新失败时，页面提示已保存，刷新资料不会重复上传。
