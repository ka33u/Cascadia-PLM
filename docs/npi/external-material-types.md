# BOM外物料类型

对应SRS第8章，录入表单提供三种类型：

| 界面名称 | API trackingType | 回复责任人 | 典型用途 |
|---|---|---|---|
| BOM外采购件 | purchase | 采购岗位 | 编码器、独立风机、客户指定采购附件 |
| 临时样机件 | material | 指定技术或制造人员 | 临时支架、转接板、试验轴套 |
| 其他物料 | other | 指定技术或制造人员 | 特殊试验用品等其他非采购跟踪物料 |

三种类型均保存为EXTERNAL来源，与ERP BOM结构分开。原`tracking_type`列为文本，所以本次不需要迁移，也不重分类既有记录。未提供trackingType的老请求继续默认purchase；空值、拼错、未知类型及不符合责任岗位的请求返回422，不能静默变成采购件。

表单分别记住三种类型当前选择的责任人；切换类型不清空名称、规格和数量。采购类型仍预选当前操作者最近使用的有效采购责任人；添加其他类型不会改变这个默认值。保存失败保留当前输入。

齐套页“物料来源”可查看全部BOM外物料，或分别筛选BOM外采购件、临时样机件和其他BOM外物料。其他物料同样按实际完成/未完成计入已满足与缺料；未跟踪BOM仍单列。影响齐套时沿用最晚承诺及待回复规则。

其他项目指定给技术/制造人员的其他物料进入“我的协作物料”，显示类型、数量和单位，支持本人回复、改期、完成及承诺历史。不会因该分配获得整个项目的读取权限。

相似项目继承保留other类型、名称、规格、数量和配置，按既定规则重建责任人；首次/当前承诺、实际完成与历史重新开始。

新增回归覆盖类型存储、非法类型拒绝、岗位校验、最近采购人不受影响、本人待办/历史、齐套预测、完成、继承重置；内存DOM测试覆盖表单切换、失败恢复和三类筛选。DOM交互测试不启动浏览器、访问网络或业务数据库，不代表实际设备布局验收。
