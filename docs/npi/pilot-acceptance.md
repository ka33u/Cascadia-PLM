## 每项目主流程记录

按真实业务进展执行，不为了验收虚构承诺、到货或完成日期。出现的问题记录复现步骤、涉及项目／物料和预期行为，再决定是否影响试运行。

| 步骤         | 核对内容                                                             | 操作人／时间、证据、结果 |
| ------------ | -------------------------------------------------------------------- | ------------------------ |
| 1 建项       | 编号、型号、负责人、样机与齐套要求、五阶段                           | 未执行                   |
| 2 导BOM      | 母件、行数、层级／父子、前导零、精确数量；原件可追溯                 | 未执行                   |
| 3 标重点     | 选择实际关键件、责任人、要求日期和是否影响齐套；普通物料无需逐项回复 | 未执行                   |
| 4 加外料     | 真实采购件名称／规格／数量、采购人、要求、技术资料                   | 未执行                   |
| 5 采购回复   | 手机查看本人任务、首次承诺；他人采购件不可修改                       | 未执行                   |
| 6 制造回复   | 工艺、工装、齐套、装配四节点填写并保存                               | 未执行                   |
| 7 预测核对   | 三种日期并列；待回复关键项标记不完整；最晚关键件及冲突正确           | 未执行                   |
| 8 改期与历史 | 有实际改期时填写原因；首次不变、旧日期／人／时间可查                 | 未执行                   |
| 9 完成与资料 | 实际发生后确认到货／完成；资料归属和权限正确                         | 未执行                   |
| 10 换版      | 有真实新BOM时保留旧版，处理变化及失效跟踪，不重建以规避历史          | 未执行                   |
| 11 驾驶舱    | 八入口职责明确；风险／逾期／待回复可下钻；正常项目可折叠             | 未执行                   |
| 12 结项      | 达到完成条件后推进；未完成关键项阻止误结项                           | 未执行                   |

同时记录桌面与手机浏览器、窗口尺寸，以及实际操作中是否出现遮挡、无法点击、信息重复或菜单找不到。制造准备看四节点待办，首页看项目风险，报表看阶段与改期结果；如仍有重复，记录具体页面与内容。
