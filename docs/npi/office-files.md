# Word与Excel资料

规格书图28-1的“项目文件”包含技术要求.docx和BOM导入文件.xlsx。本轮补齐这两类附件，项目、物料和问题资料共用的上传入口支持Word（.docx）、Excel（.xlsx），原有PDF和图片格式保留。

## 使用方式

在“项目资料”或物料/问题的“附件”入口选择文件并上传。原件保存在原生Document/Vault，下载时校验大小及SHA，归档须说明原因，归档后仍可查看和下载原件。Office作为附件下载，不提供在线编辑或预览。Excel附件与BOM导入分开：保存资料不会更新BOM，更新结构仍使用BOM管理的导入预览与确认。

技术/制造负责人按原项目范围管理资料；采购仅在本人任务上传到货资料，并按既有问题权限使用问题附件。主管仍为附件只读，计划调整权限不会扩大资料写权限。

## 格式与实现

单份不超过5MB。Office校验扩展名、压缩目录、核心部件及Content Types声明，拒绝加密、含宏、格式错配、缺少部件或超过限制的压缩包。只解压不超过512KB的类型清单，未解压图片、工作表和嵌入对象；附件目录最多2000项、声明解压总量不超过64MB。BOM导入复用原目录检查，仍保持400项/20MB原限制。此格式检查不替代病毒扫描或Office内容有效性检查。

不增加数据库表或权限，不安装新依赖；复用已安装的fflate。旧版.doc/.xls、宏文件、其他Office格式、HEIC和CAD仍未开放。

## 验证范围

31项格式/BOM单元通过，包括真实ERP样本、Word、ExcelJS生成的工作簿、UTF-16类型清单、伪装/截断/宏/加密/超限输入；5项既有附件DOM交互回归通过。限定桌面/手机浏览器验证项目Word与Excel上传、采购到货Excel上传、真实下载字节一致、归档Word下载、主管只读及无关采购拒绝。Office即使请求inline仍以附件下载。
